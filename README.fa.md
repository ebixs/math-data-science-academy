# آکادمی ریاضی و علم داده

[English](README.md) · **فارسی**

اپلیکیشنی آفلاین برای یادگیری ریاضی **از صفر تا علم داده**، به زبان **فارسی یا انگلیسی** (هر وقت بخواهی از نوار بالا عوض کن). مسیر یادگیری ساختاریافته، درس‌های عمیق، تمرین بی‌پایان با تصحیح خودکار، مرور فاصله‌دار، حل‌گر گام‌به‌گام، ابزارهای دست‌ورزی و یک دفترچهٔ پایتون واقعی با پروژه‌های دادهٔ راهنمادار را یک‌جا دارد.

> **توسعه‌دهنده: ابراهیم سلیمی** — تمامی حقوق نشر و استفادهٔ این نرم‌افزار محفوظ است و انتشار این نرم‌افزار بدون اطلاع سازنده پیگرد قانونی دارد. [LICENSE](LICENSE) را ببین.

## نصب روی مک و ویندوز

آخرین نسخه را از صفحهٔ [Releases](https://github.com/ebixs/math-data-science-academy/releases/latest) دانلود کن:

- **ویندوز:** فایل `Math-Data-Science-Academy-Setup-<نسخه>.exe` را اجرا کن. اگر SmartScreen هشدار داد: «More info» ← «Run anyway».
- **مک (Apple Silicon و Intel):** فایل `.dmg` را باز کن و برنامه را به Applications بکش. بار اول روی برنامه راست‌کلیک کن و «Open» را بزن. اگر باز نشد، در Terminal اجرا کن:
  `xattr -cr "/Applications/Math Data Science Academy.app"`

نسخهٔ دسکتاپ کاملاً آفلاین است — حتی دفترچهٔ پایتون با NumPy، pandas و matplotlib — و پیشرفت را در پوشهٔ دادهٔ برنامه ذخیره می‌کند (منوی «راهنما ← پوشهٔ ذخیرهٔ پیشرفت»). زبان منوها هم از زبان انتخاب‌شده در برنامه پیروی می‌کند.

**نصب از مرورگر (PWA):** برنامه را از آدرس `https` یا سرور محلی باز کن و در Chrome یا Edge گزینهٔ «نصب» را بزن (یا منوی پروفایل ← «نصب برنامه روی این دستگاه»). بعد از اولین بارگذاری بدون اینترنت هم کار می‌کند.

## امکانات

### مسیر یادگیری (`index.html`)
- **۶۴ مهارت در ۸ حوزه** — پایه‌های حساب، جبر، هندسه و مثلثات، ریاضیات گسسته و منطق، احتمال، آمار، جبر خطی، حسابان و بهینه‌سازی (شامل حسابان چندمتغیره، گرادیان کاهشی و بهینه‌سازی محدب).
- **نقشهٔ پیش‌نیازها**: هر مهارت می‌گوید به چه چیزی نیاز دارد و چه چیزی را باز می‌کند. سه هدف — ریاضی مدرسه، ریاضی دانشگاهی، علم داده و یادگیری ماشین — هر کدام مسیری شخصی به ترتیب پیش‌نیازها می‌سازند.
- **درس‌های عمیق دوزبانه** برای همهٔ مهارت‌ها: شهود، تعریف، مثال حل‌شده با راه‌حل پنهان، اشتباه‌های رایج، «خودت امتحان کن»، کاربرد در علم داده و **نمودارهای تعاملی با لغزنده**. درس‌های پایه مفصل‌ترین‌اند.
- **تمرین بی‌پایان با تصحیح خودکار**: برای هر مهارت یک مولد مسئله (عدد، کسر، عبارت جبری، مجموعهٔ جواب، نامعادله، نقطه و ماتریس با بررسی نمادین/عددی)، راهنمایی و راه‌حل کامل گام‌به‌گام. **تسلط = ۸ جواب درست از ۱۰ جواب آخر.**
- **آزمون تعیین سطح تطبیقی** (جست‌وجوی دودویی در هر حوزه) که مهارت‌هایی را که بلدی علامت می‌زند.
- **مرور روزانه** با تکرار فاصله‌دار (جعبه‌های لایتنر با فاصلهٔ ۱، ۳، ۷، ۱۴، ۳۰ و ۶۰ روز)، سؤال‌های مفهومی و چالش روزانه.
- XP، سطح، نقشهٔ حرارتی استریک، ۲۵ دستاورد، صفحهٔ پیشرفت به تفکیک حوزه، یادداشت‌ها و پشتیبان‌گیری JSON.

### دفترچهٔ پایتون و پروژه‌های داده (`python.html`)
پایتون واقعی در مرورگر (Pyodide) با NumPy، pandas و matplotlib، خروجی ‎`.py` و ‎`.ipynb`، و **شش پروژهٔ راهنمادار روی دادهٔ واقعی** که تمرین‌هایشان **خودکار بررسی** می‌شوند:

| پروژه | داده | ریاضیِ به‌کاررفته |
|---|---|---|
| آمار توصیفی | دیابت (۴۴۲ بیمار) | میانگین، میانه، انحراف معیار، نمرهٔ z، همبستگی |
| مونت‌کارلو | شبیه‌سازی | ترکیبیات، مسئلهٔ تولد، قضیهٔ حد مرکزی |
| رگرسیون از صفر | دیابت | تابع هزینه، مشتق جزئی، گرادیان کاهشی، معادلات نرمال |
| PCA | شراب (۱۷۸ نمونه، ۱۳ ویژگی) | کوواریانس، بردار ویژه، SVD |
| روند CO₂ | CO₂ ماهانهٔ مائونالوآ ۱۹۵۸–۲۰۰۱ | کمترین مربعات، مشتق، فصلی بودن |
| k-نزدیک‌ترین همسایه | زنبق (iris) | فاصله، دقت، ماتریس درهم‌ریختگی |

منبع و مجوز داده‌ها: [assets/data/README.md](assets/data/README.md).

### حل‌گر گام‌به‌گام (`solver.html`)
حساب، جبر (ساده‌سازی، بسط، تجزیه)، انواع معادله و نامعادله، دستگاه معادلات (حذف گاوسی)، حسابان (مشتق، انتگرال، حد، مماس، اکسترمم، سری تیلور)، ماتریس (دترمینان، وارون، RREF، مقدار ویژه) و آمار — با نمودار تعاملی، صفحه‌کلید ریاضی، پیش‌نمایش زنده، تاریخچه و پیوند اشتراک. توضیح مراحل دوزبانه است.

### ابزارهای دست‌ورزی (`math-tools.html`)
جدول ۱۰۰تایی، قاب ده‌تایی، نوار کسر، خط اعداد، ساعت، پول آموزشی، میلهٔ مهره‌ای، تختهٔ هندسه، کارت واژگان، تختهٔ یادداشت، بلوک‌های الگو، قطعات ده‌دهی، کاشی‌های جبری و مدل مساحت ضرب.

## اجرا از روی کد

نیازمندی: Python 3 (بدون کتابخانهٔ جانبی).

```bash
./start_local.command        # مک (یا: python3 server.py)
start_local.bat              # ویندوز
```

سپس http://127.0.0.1:8000 را باز کن. با سرور محلی، پیشرفت در `data/progress.json` هم ذخیره می‌شود (این فایل را به GitHub نفرست).

### ساخت نسخهٔ دسکتاپ

نیازمندی: Node.js 22.

```bash
npm install
npm start                        # اجرای برنامهٔ دسکتاپ
node desktop/fetch-pyodide.mjs   # اختیاری: پایتون آفلاین برای دفترچه
npm run dist:mac                 # یا dist:win
```

با تغییر `version` در `package.json` و push روی `main`، GitHub Actions نصب‌کننده‌های مک و ویندوز را می‌سازد و در Releases منتشر می‌کند.

## ویرایش درس‌ها

درس‌ها در `content/lessons/<شناسهٔ مهارت>.<fa|en>.md` هستند (Markdown + فرمول KaTeX + بلوک‌های آموزشی مثل `:::def`، `:::example … --- …`، `:::mistake`، `:::try` و `:::graph`). بعد از ویرایش، بستهٔ درس‌ها را دوباره بساز:

```bash
python3 scripts/build_content.py
```

## آزمون‌ها

```bash
node tests/engine.test.js && MDSA_LANG=en node tests/engine.test.js   # حل‌گر: جواب‌ها + رندر KaTeX همهٔ مراحل
node tests/learn.test.js  && MDSA_LANG=en node tests/learn.test.js    # برنامهٔ درسی، همهٔ درس‌ها، همهٔ مولدهای تمرین
node tests/desktop.test.js                                            # نسخهٔ دسکتاپ
python3 scripts/validate_curriculum.py && python3 scripts/check_inline_js.py
python3 -m unittest discover tests                                    # API سرور محلی
```

پس از افزودن یا تغییر نام فایل‌های برنامه، `python3 scripts/build_sw.py` را برای به‌روزرسانی حافظهٔ آفلاین اجرا کن.
