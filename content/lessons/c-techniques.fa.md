## وقتی تابع اولیه آشکار نیست

جدول پایه $x^n$، $e^x$ و $\sin x$ را پوشش می‌دهد. اما $\int xe^{x}\,dx$، $\int 2x\cos(x^2)\,dx$ یا $\int \frac{1}{x^2 - 1}dx$ به روش نیاز دارند. هر روش یک قاعدهٔ مشتق است که **برعکس** اجرا می‌شود: تغییر متغیر قاعدهٔ زنجیره‌ای را برمی‌گرداند و جزءبه‌جزء قاعدهٔ ضرب را.

## تغییر متغیر

:::def تغییر متغیر $u$
اگر انتگرال‌ده به شکل $f(g(x))\,g'(x)$ باشد، بگذار $u = g(x)$ و $du = g'(x)\,dx$:
$$\int f(g(x))g'(x)\,dx = \int f(u)\,du.$$
برای انتگرال معین، کران‌ها را هم عوض کن.
:::

:::example
$\displaystyle\int 2x\cos(x^2)\,dx$.
---
$u = x^2$ و $du = 2x\,dx$: $\int\cos u\,du = \sin u + C = \sin(x^2) + C$.
:::

:::example با کران
$\displaystyle\int_0^1 xe^{-x^2}\,dx$.
---
$u = -x^2$، $du = -2x\,dx$ و کران‌ها $0 \to -1$: $-\tfrac12\int_0^{-1}e^u\,du = -\tfrac12(e^{-1} - 1) = \tfrac12(1 - e^{-1}) \approx 0.316$.
:::

:::tip چه چیزی را $u$ بگیریم؟
دنبال تابع «درونی» بگرد که مشتقش هم (با یک ضریب ثابت) در انتگرال‌ده باشد.
:::

## جزءبه‌جزء

:::def انتگرال جزءبه‌جزء
$$\int u\,dv = uv - \int v\,du.$$
از $(uv)' = u'v + uv'$ می‌آید.
:::

:::example
$\displaystyle\int xe^x\,dx$.
---
$u = x$ و $dv = e^x dx$: $du = dx$ و $v = e^x$. $xe^x - \int e^x\,dx = e^x(x - 1) + C$.
:::

:::example
$\displaystyle\int \ln x\,dx$.
---
$u = \ln x$ و $dv = dx$: $x\ln x - \int x\cdot\tfrac1x\,dx = x\ln x - x + C$.
:::

:::tip ترتیب انتخاب
$u$ را به این ترتیب انتخاب کن: لگاریتم، وارون مثلثاتی، جبری (توان‌ها)، مثلثاتی، نمایی. تابعی که با مشتق گرفتن ساده‌تر می‌شود باید $u$ باشد.
:::

## کسرهای جزئی

یک تابع گویا را به تکه‌های ساده‌تر بشکن:

:::example
$\displaystyle\int\frac{1}{x^2 - 1}\,dx$.
---
$\dfrac{1}{(x - 1)(x + 1)} = \dfrac{A}{x - 1} + \dfrac{B}{x + 1}$ می‌دهد $A = \tfrac12$ و $B = -\tfrac12$.
پس $\tfrac12\ln|x - 1| - \tfrac12\ln|x + 1| + C = \tfrac12\ln\left|\dfrac{x - 1}{x + 1}\right| + C$.
:::

## انتگرال ناسره

انتگرال روی بازهٔ نامتناهی یک حد است:
$$\int_0^\infty e^{-x}\,dx = \lim_{b\to\infty}\left[-e^{-x}\right]_0^b = 1.$$
چنین انتگرال‌هایی توزیع‌های احتمال را تعریف می‌کنند: چگالی نمایی $\lambda e^{-\lambda x}$ روی $[0, \infty)$ انتگرالی برابر ۱ دارد.

## اشتباه‌های رایج

:::mistake فراموش کردن $du$
در تغییر متغیر، همهٔ $x$ها (از جمله $dx$) باید جایگزین شوند.
:::

:::mistake انتخاب $u$ای که سخت‌تر می‌شود
در $\int xe^x dx$، انتخاب $u = e^x$ به $\int \tfrac{x^2}{2}e^x dx$ می‌رسد — بدتر.
:::

## خودت امتحان کن

:::try
$\displaystyle\int \frac{2x}{x^2 + 1}\,dx$.
---
$\ln(x^2 + 1) + C$.
:::

:::try
$\displaystyle\int x\sin x\,dx$.
---
با $u = x$: $-x\cos x + \sin x + C$.
:::

:::try
$\displaystyle\int_1^\infty \frac{1}{x^2}\,dx$.
---
$\lim_{b\to\infty}(1 - \tfrac1b) = 1$.
:::

:::ds در علم داده
امید ریاضی متغیر تصادفی نمایی، $\int_0^\infty x\lambda e^{-\lambda x}dx = \tfrac1\lambda$، با جزءبه‌جزء به دست می‌آید. در عمل ابزارهای نمادین (`sympy.integrate`) یا انتگرال‌گیری عددی جبر را انجام می‌دهند — اما دانستن روش‌ها می‌گوید چه چیزی ممکن است.
:::

## خلاصه

- تغییر متغیر قاعدهٔ زنجیره‌ای را برمی‌گرداند؛ جزءبه‌جزء قاعدهٔ ضرب را.
- کسرهای جزئی تابع گویا را می‌شکنند.
- انتگرال ناسره یک حد است.
