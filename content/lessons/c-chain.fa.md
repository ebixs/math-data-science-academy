## مشتق تابع‌های تودرتو

$\sin(3x^2)$، $e^{-x^2/2}$، $\ln(1 + e^x)$ و $\sqrt{1 - x^2}$: بیشتر فرمول‌های واقعی **ترکیب** تابع‌اند — یک تابع درون تابعی دیگر. **قاعدهٔ زنجیره‌ای** از آن‌ها مشتق می‌گیرد و دقیقاً همان الگوریتم «پس‌انتشار» است که هر شبکهٔ عصبی را آموزش می‌دهد.

:::def قاعدهٔ زنجیره‌ای
اگر $y = f(g(x))$، آن‌گاه
$$\frac{dy}{dx} = f'(g(x))\cdot g'(x).$$
در نماد لایب‌نیتس با $u = g(x)$: $\dfrac{dy}{dx} = \dfrac{dy}{du}\cdot\dfrac{du}{dx}$.
:::

:::why آهنگ‌ها ضرب می‌شوند
اگر $u$ سه برابر سریع‌تر از $x$ تغییر کند و $y$ پنج برابر سریع‌تر از $u$، آن‌گاه $y$ پانزده برابر ($5\times3$) سریع‌تر از $x$ تغییر می‌کند. مثل چرخ‌دنده‌ها: آهنگ تابع بیرونی ضرب در آهنگ تابع درونی.
:::

:::example
از $(3x^2 + 1)^5$، $\sin(4x)$ و $e^{-x^2}$ مشتق بگیر.
---
$5(3x^2 + 1)^4\cdot 6x = 30x(3x^2 + 1)^4$. $4\cos(4x)$. $-2xe^{-x^2}$.
:::

:::example لایه‌ها
$\dfrac{d}{dx}\ln(\cos(x^2))$.
---
بیرونی $\ln$، میانی $\cos$، درونی $x^2$: $\dfrac{1}{\cos(x^2)}\cdot(-\sin(x^2))\cdot 2x = -2x\tan(x^2)$.
:::

## تابع‌های متعالی

| تابع | مشتق |
|---|---|
| $e^{kx}$ | $ke^{kx}$ |
| $a^x$ | $a^x\ln a$ |
| $\ln(g(x))$ | $\dfrac{g'(x)}{g(x)}$ |
| $\log_a x$ | $\dfrac{1}{x\ln a}$ |
| $\tan x$ | $\sec^2x$ |
| $\arctan x$ | $\dfrac{1}{1 + x^2}$ |
| $\arcsin x$ | $\dfrac{1}{\sqrt{1 - x^2}}$ |

:::example تابع سیگموید
$\sigma(x) = \dfrac{1}{1 + e^{-x}}$. نشان بده $\sigma'(x) = \sigma(x)(1 - \sigma(x))$.
---
$\sigma = (1 + e^{-x})^{-1}$، پس $\sigma' = -(1 + e^{-x})^{-2}\cdot(-e^{-x}) = \dfrac{e^{-x}}{(1 + e^{-x})^2} = \dfrac{1}{1 + e^{-x}}\cdot\dfrac{e^{-x}}{1 + e^{-x}} = \sigma(1 - \sigma)$.
:::

## مشتق ضمنی

برای $x^2 + y^2 = 25$، از دو طرف مشتق بگیر و $y$ را تابعی از $x$ بدان: $2x + 2y\,y' = 0 \Rightarrow y' = -\dfrac{x}{y}$. در $(3, 4)$ شیب $-\tfrac34$ است.

## اشتباه‌های رایج

:::mistake فراموش کردن مشتق درونی
$\dfrac{d}{dx}\sin(5x) = 5\cos(5x)$، نه $\cos(5x)$.
:::

:::mistake تغییر دادن درون
$\dfrac{d}{dx}(x^2 + 1)^3 = 3(x^2 + 1)^2\cdot2x$ — درون در مشتق بیرونی همان $(x^2 + 1)$ می‌ماند.
:::

## خودت امتحان کن

:::try
$\dfrac{d}{dx}\sqrt{1 + x^2}$.
---
$\dfrac{x}{\sqrt{1 + x^2}}$.
:::

:::try
$\dfrac{d}{dx}\, 3^{2x}$.
---
$2\ln3\cdot 3^{2x}$.
:::

:::try
$\dfrac{d}{dx}\ln(1 + e^x)$ (تابع «سافت‌پلاس»).
---
$\dfrac{e^x}{1 + e^x} = \sigma(x)$.
:::

:::ds در علم داده
**پس‌انتشار** همان قاعدهٔ زنجیره‌ای است که لایه به لایه از تابع هزینه تا هر وزن به عقب اعمال می‌شود: $\tfrac{\partial L}{\partial w} = \tfrac{\partial L}{\partial \hat y}\cdot\tfrac{\partial \hat y}{\partial z}\cdot\tfrac{\partial z}{\partial w}$. اتحاد $\sigma' = \sigma(1 - \sigma)$ گرادیان رگرسیون لجستیک را به‌طرز شگفت‌انگیزی ساده می‌کند.
:::

## خلاصه

- $(f\circ g)' = f'(g(x))\,g'(x)$: مشتق بیرونی (با درون دست‌نخورده) × مشتق درونی.
- $\tfrac{d}{dx}e^{g} = g'e^g$ و $\tfrac{d}{dx}\ln g = \tfrac{g'}{g}$.
- پس‌انتشار = قاعدهٔ زنجیره‌ای.
