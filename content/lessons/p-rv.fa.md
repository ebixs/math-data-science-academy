## عددهایی که از شانس می‌آیند

**متغیر تصادفی** به هر برآمد یک آزمایش تصادفی عددی نسبت می‌دهد: تعداد شیرها در ۱۰ پرتاب، سود یک شرط، فروش فردا. وقتی برآمدها عدد شدند، می‌توانیم **میانگین** مورد انتظار (امید ریاضی) و میزان **پراکندگی** نتیجه‌ها (واریانس) را بپرسیم — دو خلاصهٔ مهم کل آمار.

## توزیع

:::def متغیر تصادفی گسسته
متغیر تصادفی گسستهٔ $X$ مقدارهای $x_1, x_2, \dots$ را با احتمال‌های $p_i = P(X = x_i)$ می‌گیرد که $p_i \ge 0$ و $\sum p_i = 1$. فهرست مقدارها و احتمال‌ها **توزیع** آن است.
:::

:::example
$X$ = تعداد شیرها در ۲ پرتاب سکهٔ سالم.
---
$P(X = 0) = \tfrac14$، $P(X = 1) = \tfrac12$، $P(X = 2) = \tfrac14$.
:::

## امید ریاضی

:::def امید ریاضی
$$E[X] = \mu = \sum_i x_i\,p_i.$$
میانگین درازمدت است اگر آزمایش بارها تکرار شود — میانگینی وزن‌دار با احتمال‌ها.
:::

:::example یک بازی
۵ می‌پردازی تا تاسی بیندازی؛ اگر ۶ بیاید ۱۲ می‌بری وگرنه هیچ. ارزشش را دارد؟
---
سود خالص: $+7$ با احتمال $\tfrac16$ و $-5$ با احتمال $\tfrac56$. $E = \tfrac76 - \tfrac{25}{6} = -3$. به‌طور میانگین در هر بازی ۳ می‌بازی.
:::

:::def خطی بودن امید ریاضی
$$E[aX + b] = aE[X] + b,\qquad E[X + Y] = E[X] + E[Y]$$
— همیشه، حتی اگر $X$ و $Y$ وابسته باشند.
:::

## واریانس و انحراف معیار

:::def واریانس
$$\operatorname{Var}(X) = E\big[(X - \mu)^2\big] = E[X^2] - \mu^2,\qquad \sigma = \sqrt{\operatorname{Var}(X)}.$$
$\operatorname{Var}(aX + b) = a^2\operatorname{Var}(X)$؛ برای $X, Y$ **مستقل**: $\operatorname{Var}(X + Y) = \operatorname{Var}X + \operatorname{Var}Y$.
:::

:::example
برای $X$ دو پرتاب بالا: $\mu = 0(\tfrac14) + 1(\tfrac12) + 2(\tfrac14) = 1$.
---
$E[X^2] = 0 + \tfrac12 + 4\cdot\tfrac14 = 1.5$، پس $\operatorname{Var} = 1.5 - 1 = 0.5$ و $\sigma \approx 0.71$.
:::

:::why چرا انحراف‌ها را به توان دو می‌رسانیم؟
میانگین انحراف‌های $x - \mu$ صفر است (مثبت‌ها منفی‌ها را خنثی می‌کنند). توان دو همه را مثبت می‌کند و انحراف‌های بزرگ را بیشتر جریمه می‌کند. جذر، یکا را برمی‌گرداند.
:::

## متغیر تصادفی پیوسته (پیش‌نمایش)

قد یا زمان انتظار هر مقداری در یک بازه را می‌گیرند. آن‌وقت احتمال‌ها **مساحت** زیر منحنی چگالی $f(x)$ هستند: $P(a \le X \le b) = \int_a^b f(x)\,dx$ و برای هر مقدار تکی $P(X = a) = 0$. توزیع نرمال مهم‌ترین مثال است.

## اشتباه‌های رایج

:::mistake $E[X^2] = (E[X])^2$
در حالت کلی نه: اختلافشان دقیقاً واریانس است.
:::

:::mistake $\operatorname{Var}(X - Y) = \operatorname{Var}X - \operatorname{Var}Y$
برای متغیرهای مستقل، واریانس‌ها حتی برای تفاضل هم **جمع** می‌شوند.
:::

## خودت امتحان کن

:::try
$X$ مقدارهای ۱، ۲ و ۳ را با احتمال‌های ۰٫۲، ۰٫۵ و ۰٫۳ می‌گیرد. $E[X]$ و $\operatorname{Var}(X)$؟
---
$E = 0.2 + 1 + 0.9 = 2.1$. $E[X^2] = 0.2 + 2 + 2.7 = 4.9$. $\operatorname{Var} = 4.9 - 4.41 = 0.49$.
:::

:::try
اگر $E[X] = 4$ و $\operatorname{Var}(X) = 9$، $E[3X - 2]$ و انحراف معیار $3X - 2$ را پیدا کن.
---
$E = 10$؛ $\operatorname{Var} = 81$ و انحراف معیار $= 9$.
:::

:::ds در علم داده
مدل‌ها امید زیان را کمینه می‌کنند؛ میانگین و واریانس نمونه (`x.mean()` و `x.var(ddof=1)`) تخمین‌هایی از $\mu$ و $\sigma^2$ هستند. خطی بودن امید ریاضی پشت محاسبه‌های ساده و قدرتمند زیادی است، مثل درآمد مورد انتظار کل مشتریان.
:::

## خلاصه

- توزیع: مقدارها با احتمال‌هایی که جمعشان ۱ است.
- $E[X] = \sum x p$ و خطی است. $\operatorname{Var} = E[X^2] - \mu^2$ و با $a^2$ مقیاس می‌گیرد.
- برای متغیرهای مستقل، واریانس‌ها جمع می‌شوند.
