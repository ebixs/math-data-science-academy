## اهداف یادگیری

پس از این فصل باید بتوانی متغیر تعریف کنی، شرط و حلقه بنویسی، تابع بسازی، خطاهای رایج را بررسی کنی، دادهٔ CSV را با pandas بخوانی، کیفیت داده را بررسی و یک گزارش روشن تولید کنی.

## بخش ۱ — نخستین برنامه و متغیرها

~~~python
print("سلام دنیا")
print(2 + 3 * 4)
~~~

خروجی خط دوم 14 است، چون ضرب پیش از جمع انجام می‌شود. متغیر نامی برای ارجاع به یک مقدار است. نوع‌های رایج عبارت‌اند از int برای عدد صحیح، float برای اعشار، str برای متن و bool برای درست/نادرست.

~~~python
age = 32
price = 19.5
city = "Tehran"
is_active = True
print(age, price, city, is_active)
~~~

علامت = برای انتساب است؛ مقایسهٔ برابری با == نوشته می‌شود. متن و عدد را نمی‌توان بدون توجه به نوع با هم جمع کرد.

### مثال حل‌شده
~~~python
price = 12.5
count = 4
total = price * count
print(total)
~~~
نتیجه 50.0 است.

**تمرین:** اگر قیمت 7.5 و تعداد 6 باشد، هزینهٔ کل چقدر است؟

**پاسخ:** 7.5×6=45.

## بخش ۲ — شرط و منطق

شرط if مسیر اجرای برنامه را انتخاب می‌کند. elif برای حالت‌های بعدی و else برای حالت باقی‌مانده است. تورفتگی در پایتون بخشی از ساختار کد است.

~~~python
score = 72
if score >= 60:
    result = "قبول"
else:
    result = "نیاز به تمرین"
print(result)
~~~

مرز را روشن تعریف کن: اگر حد قبولی 60 باشد، آیا 60 هم قبول است؟ در مثال بالا بله، چون از >= استفاده شده است.

**تمرین:** برنامه‌ای بنویس که عدد n را به مثبت، صفر یا منفی دسته‌بندی کند.

**پاسخ نمونه:**
~~~python
if n > 0:
    print("مثبت")
elif n == 0:
    print("صفر")
else:
    print("منفی")
~~~

## بخش ۳ — فهرست و حلقه

فهرست مجموعه‌ای مرتب از مقدارهاست و اندیس آن از صفر شروع می‌شود. حلقهٔ for روی عناصر حرکت می‌کند. while تا وقتی شرط برقرار است تکرار می‌شود؛ شرط توقف را فراموش نکن تا حلقه بی‌نهایت نشود.

~~~python
values = [2, 4, 6, 8]
total = 0
for value in values:
    total += value
print(total)
~~~

نتیجه 20 است. در هر دور، یک مقدار به مجموع قبلی اضافه می‌شود.

**تمرین‌ها:**
1. مجموع [1,3,5,7] را با حلقه حساب کن.
2. از [4,12,7,20] فقط مقادیر بزرگ‌تر از 10 را جدا کن.
3. چرا range(4) شامل عدد 4 نیست؟

**پاسخ‌ها:** 16؛ [12,20]؛ چون مقدارها از صفر تا 3 هستند.

## بخش ۴ — تابع و خطاهای ورودی

تابع با def تعریف می‌شود. پارامتر ورودی را دریافت می‌کند و return نتیجه را برمی‌گرداند. رفتار تابع برای ورودی‌های مرزی باید روشن باشد.

~~~python
def mean(values):
    if len(values) == 0:
        raise ValueError("فهرست خالی است")
    return sum(values) / len(values)

print(mean([2, 4, 6]))
~~~

خروجی 4.0 است. فهرست خالی را باید بررسی کرد، چون تقسیم بر صفر خطا می‌دهد.

**تمرین:** تابعی بنویس که بیشترین مقدار را برگرداند و فهرست خالی را مدیریت کند.

**پاسخ نمونه:**
~~~python
def maximum_value(values):
    if not values:
        raise ValueError("فهرست خالی است")
    return max(values)
~~~

## بخش ۵ — دیکشنری، فایل و محیط پروژه

دیکشنری مقدارها را با کلید نگه می‌دارد. برای مثال، یک سفارش می‌تواند شناسه، مبلغ و وضعیت داشته باشد. شناسه معمولاً کمیت قابل جمع نیست؛ چون یک کد شناسایی است، نه مبلغ.

برای پروژه‌های قابل بازتولید، محیط مجازی وابستگی‌ها را جدا می‌کند:

~~~bash

~~~

در ویندوز دستور فعال‌سازی متفاوت است. نسخهٔ کتابخانه‌ها و دستور اجرای پروژه را مستند کن تا فرد دیگری بتواند نتیجه را بازتولید کند.

## بخش ۶ — خواندن CSV با pandas

pandas کتابخانه‌ای برای داده‌های جدولی است. DataFrame شبیه جدول است؛ هر سطر معمولاً یک مشاهده و هر ستون یک متغیر را نشان می‌دهد.

~~~python
import pandas as pd

df = pd.read_csv("orders.csv")
print(df.head())
print(df.shape)
print(df.dtypes)
~~~

- head چند ردیف نخست را نشان می‌دهد.
- shape تعداد ردیف و ستون را می‌دهد.
- dtypes نوع ذخیره‌شدهٔ هر ستون را نشان می‌دهد.

**تمرین:** چگونه تعداد ردیف و ستون را بررسی می‌کنی؟

**پاسخ:** با df.shape.

## بخش ۷ — کیفیت داده: گمشده، تکراری و نامعتبر

مقدار گمشده، صفر و رشتهٔ خالی یکسان نیستند. تکرار یک ردیف هم لزوماً خطا نیست؛ دو سفارش ممکن است به‌طور مشروع مقدار یکسان داشته باشند. پیش از حذف، تعریف رکورد و کلید یکتا را مشخص کن.

~~~python
print(df.isna().sum())
print(df.duplicated().sum())
print(df.describe(include="all"))
~~~

اگر مبلغ منفی دیده شد، فوراً حذفش نکن؛ شاید بازپرداخت یا اصلاح حسابداری باشد. تصمیم‌های پاک‌سازی را مستند کن و فایل خام را دست‌نخورده نگه دار.

**تمرین:** سه بررسی پیش از محاسبهٔ میانگین مبلغ سفارش نام ببر.

**پاسخ نمونه:** نوع و واحد ستون، مقدارهای گمشده یا نامعتبر، تکرار شناسه و تعریف هر ردیف.

## بخش ۸ — فیلتر، گروه‌بندی و خلاصه‌سازی

فیلتر باید به پرسش تحلیلی مربوط باشد. groupby شاخص‌ها را به تفکیک گروه محاسبه می‌کند.

~~~python
completed = df[df["status"] == "completed"]
summary = completed.groupby("city")["amount"].agg(["count", "mean", "sum"])
print(summary)
~~~

این کد سفارش‌های تکمیل‌شده را انتخاب می‌کند و برای هر شهر تعداد، میانگین و مجموع مبلغ را می‌سازد. تفسیر آن به تعریف وضعیت و واحد مبلغ وابسته است.

**تمرین:** مجموع مبلغ را برای هر وضعیت سفارش محاسبه کن.

**پاسخ:** df.groupby("status")["amount"].sum()؛ پیش از محاسبه مطمئن شو مبلغ عددی و واحد پول یکسان دارد.

## بخش ۹ — نمودار و روایت داده

نمودار برای پاسخ به پرسش مشخص ساخته می‌شود:
- نمودار خطی برای روند زمانی.
- نمودار میله‌ای برای مقایسهٔ گروه‌ها.
- هیستوگرام برای توزیع متغیر عددی.
- نمودار پراکندگی برای رابطهٔ دو متغیر عددی.

~~~python
import matplotlib.pyplot as plt

monthly = df.groupby("month")["amount"].sum()
monthly.plot(kind="line", marker="o")
plt.title("Monthly amount")
plt.xlabel("Month")
plt.ylabel("Amount")
plt.tight_layout()
plt.show()
~~~

عنوان، واحد، بازهٔ زمانی و منبع داده را مشخص کن. همبستگی روی نمودار به‌تنهایی علیت را ثابت نمی‌کند.

**تمرین:** برای مقایسهٔ فروش چهار شعبه و نمایش فروش روزانه چه نمودارهایی مناسب‌اند؟

**پاسخ:** نمودار میله‌ای برای چهار شعبه و نمودار خطی برای روند روزانه.

## بخش ۱۰ — پروژهٔ انتهابه‌انتها

یک CSV ساختگی یا عمومی با ستون‌های تاریخ، شعبه، مبلغ و وضعیت سفارش انتخاب کن.

1. پرسش را روشن بنویس؛ مثلاً «مجموع فروش تکمیل‌شده در هر ماه چگونه تغییر کرده؟»
2. منبع داده و تعریف هر ردیف را مستند کن.
3. شکل، نوع ستون‌ها، گمشده‌ها، تکراری‌ها و مقدارهای نامعتبر را بررسی کن.
4. قوانین پاک‌سازی را ثبت کن و فایل خام را حفظ کن.

6. دو نمودار مناسب بساز و هر کدام را با یک پرسش مرتبط کن.
7. سه یافته، دو محدودیت و یک پیشنهاد برای دادهٔ بهتر بنویس.
8. کد و دستور اجرا را در README قرار بده.
