# آکادمی ریاضی و علم داده

اپلیکیشن آموزشی فارسی و راست‌چین برای یادگیری ریاضی و ورود مرحله‌ای به علم داده؛ از مبانی ریاضی تا آمار، جبر خطی، پایتون، SQL، تحلیل داده و یادگیری ماشین.

## اجرا روی macOS

نیازمندی: Python 3 (بدون کتابخانهٔ جانبی).

1. مخزن را دانلود یا clone کن.
2. در Terminal وارد پوشهٔ پروژه شو.
3. اجرا کن:

```bash
chmod +x start_local.command
./start_local.command
```

اگر مرورگر خودکار باز نشد، http://127.0.0.1:8000 را باز کن. برای توقف سرور `Control+C` را بزن.

روش جایگزین: `python3 server.py`

## اجرا روی Windows

روی `start_local.bat` دوبار کلیک کن. Python 3 باید نصب باشد.

## امکانات برنامه

- ۱۲ درس آغازین با توضیحات پایه، مثال و کاربرد در علم داده
- تمرینگاه با سؤال‌هایی از ریاضی، آمار، جبر خطی، پایتون و یادگیری ماشین
- راهنمایی مرحله‌ای و پاسخ تشریحی
- نقشهٔ راه Data Science و گزارش پیشرفت
- یادداشت کلی و یادداشت اختصاصی هر درس
- خروجی پشتیبان JSON و بازیابی آن
- ذخیره در مرورگر و فایل پروژهٔ محلی `data/progress.json`
- بدون نیاز به اینترنت یا کتابخانهٔ جانبی برای اجرای محلی

## ذخیره‌سازی روی سیستم

وقتی برنامه را با `start_local.command` یا `python3 server.py` اجرا کنی، پیشرفت و یادداشت‌ها از طریق سرور محلی در `data/progress.json` ذخیره می‌شوند. پوشهٔ `data` هنگام اولین ذخیره ساخته می‌شود.

**فایل محلی `data/progress.json` را به GitHub ارسال نکن**؛ ممکن است یادداشت‌ها یا اطلاعات شخصی داشته باشد. اگر `index.html` را مستقیماً با آدرس `file://` باز کنی، ذخیره در پوشهٔ پروژه در دسترس نیست؛ از سرور محلی استفاده کن. برای انتقال بین دستگاه‌ها، خروجی JSON بگیر و آن را در دستگاه دیگر بازیابی کن.

## بررسی ساختار آموزشی

برای اجرای بررسی ساختاری فصل‌ها با Python 3:

```bash
python3 scripts/validate_curriculum.py
```

این بررسی وجود ۱۰ فصل، نشانگرهای آزمون/پاسخ‌نامه/پروژه، جفت بودن حصارهای کد Markdown و چند نشانهٔ ساختاری را می‌سنجد. این ابزار جایگزین اجرای واقعی برنامه، بازبینی مستقل همهٔ پاسخ‌ها یا آزمون مرورگر نیست.

## ساختار مهم مخزن

- `index.html` — رابط کاربری، درس‌ها و تمرین‌ها
- `server.py` — سرور محلی و API ذخیره‌سازی
- `data/progress.json` — اطلاعات محلی ساخته‌شده هنگام ذخیره
- `start_local.command` — اجرای سریع در macOS
- `start_local.bat` — اجرای سریع در Windows
- `chapters/` — کتابچه‌های آموزشی تکمیلی
- `scripts/validate_curriculum.py` — بررسی ساختاری فصل‌ها

کتابچه‌ها نسخه‌های مستقل اولیه‌اند و باید به‌صورت مرحله‌ای با بازبینی محاسبات، پاسخ‌نامه‌ها، مثال‌های کدنویسی و تعاملات برنامه توسعه یابند. پیوند به منابع آموزشی به معنی تأیید رسمی آکادمی از سوی دانشگاه‌ها یا شرکت‌ها نیست.
