# آکادمی ریاضی و علم داده

اپلیکیشن آموزشی فارسی و راست‌چین برای یادگیری ریاضی و ورود مرحله‌ای به علم داده؛ از مبانی تا آمار، جبر خطی، پایتون و یادگیری ماشین.

## اجرا روی macOS

نیازمندی: Python 3 (بدون کتابخانه جانبی).

1. مخزن را دانلود یا clone کن.
2. در Terminal وارد پوشه پروژه شو.
3. اجرا کن:

```bash
chmod +x start_local.command
./start_local.command
```

اگر مرورگر خودکار باز نشد، http://127.0.0.1:8000 را باز کن. برای توقف سرور Control+C را بزن.

روش جایگزین: `python3 server.py`

## اجرا روی Windows

روی `start_local.bat` دوبار کلیک کن. Python 3 باید نصب باشد.

## امکانات

- ۱۲ درس آغازین با توضیح پایه، مثال و کاربرد در علم داده
- توضیحات تکمیلی و تمرین تشریحی اختصاصی برای هر درس
- تمرینگاه با ۱۶ سؤال از ریاضی، آمار، جبر خطی، پایتون و یادگیری ماشین
- راهنمایی مرحله‌ای و پاسخ تشریحی
- نقشه راه Data Science و گزارش پیشرفت
- یادداشت کلی و یادداشت اختصاصی هر درس
- خروجی پشتیبان JSON و بازیابی آن
- ذخیره محلی در مرورگر و فایل پروژه `data/progress.json`
- بدون نیاز به اینترنت یا کتابخانه جانبی

## ذخیره‌سازی روی سیستم

هنگامی که برنامه را با `start_local.command` یا `python3 server.py` اجرا کنی، پیشرفت و یادداشت‌ها از طریق سرور محلی در `data/progress.json` ذخیره می‌شوند. پوشه `data` هنگام اولین ذخیره ساخته می‌شود. این فایل محلی را به GitHub ارسال نکن؛ ممکن است یادداشت‌ها و اطلاعات شخصی تو را داشته باشد.

اگر فایل را مستقیماً با دوبار کلیک و آدرس `file://` باز کنی، ذخیره در پوشه پروژه در دسترس نیست؛ باید از سرور محلی استفاده کنی. اطلاعات مرورگر در `localStorage` نیز نگه داشته می‌شود. برای پشتیبان‌گیری یا انتقال بین دستگاه‌ها از خروجی JSON استفاده کن.

## ساختار

- `index.html` — رابط کاربری، درس‌ها و تمرین‌ها
- `server.py` — سرور محلی و API ذخیره‌سازی
- `data/progress.json` — اطلاعات محلی ساخته‌شده هنگام ذخیره
- `start_local.command` — اجرای سریع در macOS
- `start_local.bat` — اجرای سریع در Windows
