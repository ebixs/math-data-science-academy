# آکادمی ریاضی و علم داده

اپلیکیشن فارسی برای یادگیری و تمرین ریاضی، هندسه، آمار و مسیر ورود به علم داده؛ از مبانی تا پایتون و یادگیری ماشین.

## اجرای آفلاین روی macOS

نیازمندی: Python 3. به هیچ کتابخانه جانبی نیاز نیست.

1. مخزن را دانلود یا clone کنید.
2. از Terminal وارد پوشه پروژه شوید.
3. اجرا کنید:

```bash
chmod +x start_local.command
./start_local.command
```

اگر مرورگر خودکار باز نشد، آدرس http://127.0.0.1:8000 را باز کنید.
برای توقف سرور، در Terminal کلیدهای Control+C را بزنید.

روش جایگزین:

```bash
python3 server.py
```

## اجرا روی Windows

روی start_local.bat دوبار کلیک کنید. Python 3 باید نصب باشد.

## امکانات

- رابط کاربری فارسی و راست‌چین
- ۱۲ درس آغازین در حساب، جبر، هندسه، احتمال، آمار، جبر خطی، حسابان، پایتون و یادگیری ماشین
- آزمون کوتاه همراه بازخورد
- نقشه راه مرحله‌ای Data Science
- پیگیری پیشرفت و ثبت پاسخ‌های صحیح
- ذخیره پیشرفت در localStorage مرورگر
- اجرا روی 127.0.0.1 و بدون وابستگی به اینترنت

## نکته درباره پیشرفت

اطلاعات پیشرفت در همان مرورگر و پروفایل ذخیره می‌شود. با پاک کردن داده‌های مرورگر یا تغییر مرورگر، این اطلاعات ممکن است از دسترس خارج شود.

## ساختار فایل‌ها

- index.html — رابط کاربری و درس‌ها
- server.py — سرور محلی با کتابخانه استاندارد پایتون
- start_local.command — اجرای سریع در macOS
- start_local.bat — اجرای سریع در Windows
